# styles/

Reserved for global design tokens (CSS custom properties / Tailwind theme extension) once Phase 5 implementation begins.

No UI is being built in this phase. The tokens this folder will eventually hold — type scale, color palette, spacing scale, motion durations/easings — are fully specified in [`../docs/design-system.md`](../docs/design-system.md). When Phase 5 starts, translate that document into `styles/tokens.css` (or a Tailwind `theme.extend` block in `tailwind.config`) rather than inventing new values here.
